Supported formats: .csv, .xlsx, .xls

Supported Columns

  • name / full_name: Required (e.g. "John Smith")
  • email: Required & unique (e.g. "john@university.edu")
  • role: student, faculty, admin, parent, hr, accountant (default: student)
  • phone: Phone number
  • password: Initial password (default: "ChangeMe123!")
  • course / course_name: Course name (e.g. "B.Tech", "MBA")
  • stream / stream_name / branch: Stream/Branch (e.g. "Computer Science", "Finance")
  • batch / batch_name: Batch (e.g. "2024-2028")
  • section / section_name: Section (e.g. "A", "B")
  • enrollment_number: Student Enrollment ID (auto-generated if empty)
  • date_of_birth: Format: YYYY-MM-DD (e.g. "2004-05-15")
  • gender: Male, Female, Other

Import Tips & Guidance

Automatic Entity Creation

If a specified Course, Stream, Batch, or Section does not already exist in the database, the system will automatically create it and tag the student to it!

Duplicate Check

If an email address already exists in the system, that row will be skipped with a warning message so existing data is preserved.

Default Credentials

If password is left blank in the uploaded file, the user will be created with default password ChangeMe123!.
