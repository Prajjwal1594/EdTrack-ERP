Paste this single line before the closing </body> tag on your website. It adds an interactive floating admission button and inquiry modal instantly:

<script src="{{ request.host_url }}static/js/edtrack-admission-widget.js" data-school="{{ current_user.college.code if current_user.college else 'EWIU' }}"></script>

Use this form directly inside your website's contact or admissions page:

<form action="{{ request.host_url }}api/admissions/inquire" method="POST">
  <input type="hidden" name="school_code" value="{{ current_user.college.code if current_user.college else 'EWIU' }}" />
  <!-- Optional redirect back to your site: -->
  <!-- <input type="hidden" name="redirect_url" value="https://yourschool.com/thank-you.html" /> -->

  <input type="text" name="student_name" placeholder="Student Full Name" required />
  <input type="text" name="parent_name" placeholder="Parent / Guardian Name" />
  <input type="tel" name="phone" placeholder="Phone / Mobile Number" required />
  <input type="email" name="email" placeholder="Email Address" />
  <input type="text" name="target_class" placeholder="Class / Grade Applying For" />
  <textarea name="notes" placeholder="Questions or Message"></textarea>

  <button type="submit">Submit Admission Enquiry</button>
</form>

For modern websites (React, Vue, or custom JS forms), submit asynchronously using fetch():

fetch('{{ request.host_url }}api/admissions/inquire', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    school_code: '{{ current_user.college.code if current_user.college else 'EWIU' }}',
    student_name: 'John Doe',
    parent_name: 'Jane Doe',
    phone: '+91 9876543210',
    email: 'jane@example.com',
    target_class: 'Grade 5',
    notes: 'Interested in sports facilities'
  })
})
.then(res => res.json())
.then(data => console.log('Enquiry received! ID:', data.enquiry_id));
